

# Best Egg Hub

Script focado para **Steal an Egg** no estilo Lennon Hub.

Mostra os melhores ovos do mapa com valor estimado e teleporte teleguiado.

---

## Características

- Exibe o **melhor ovo** do mapa em destaque
- Lista os **Top 6** ovos por valor estimado
- Calcula valor aproximado (índice + tamanho do ovo)
- **TELEGUIADO** (clique no card do melhor ovo)
- **LOOP** automático para o melhor ovo
- Interface limpa e organizada
- Arrastável
